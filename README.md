# 恐怖阿嬤的英文逃脫

高中英文單字／文法／克漏字的 2D 逃脫遊戲。單一 `index.html`，沒有任何外部相依，手機／平板／電腦直接開就能玩。

**遊戲網址**：https://priscillalearn-ops.github.io/granny-escape-b3l1/

`GSAT` 這一課的三種題型分別是：字義（中英互選）、字根字首拆解、例句填空，
題目取自《GSAT 英文單字旗艦版：從字根邏輯到必背搭配詞》共 904 個單字。

按「開始逃脫」後會先出現**選擇範圍**畫面，可以單選一課，也可以複選好幾課混著出題。

## 遊戲內容
- 兩關：第 1 關「阿嬤的家」、第 2 關「阿嬤的醫院」
- 虛擬搖桿操控（左半邊按住拖動，推到底＝跑）
- 🤡 紅鼻子無敵道具：8 秒無敵，撞到阿嬤讓她愣 4 秒；每答對 5 題充能一次
- 自動存檔（存在玩家自己的瀏覽器），結束後有錯題複習

## 要新增一課的題目

編輯 `index.html`，找到最上面的 `const UNITS=[` ，在陣列裡再加一個物件：

```js
{
 id:"B3L2",                         // 代號，不能跟別課重複
 name:"B3 L2　課文標題",             // 選單上顯示的全名
 short:"B3 L2",                     // HUD 上顯示的短名
 src:{ v:"B3 L2 單字・片語",
       g:"B3 L2 文法：⋯⋯",
       c:"B3 L2 克漏字・文意選填" },  // 答題時顯示在題目上方的出處
 v:[  // 單字、片語
   ["「僱用」的英文是？", ["employ","deserve","adapt","collaborate"], 0, "employ (vt.) 僱用"],
 ],
 g:[  // 文法
   ["Kevin promised ____ the report.", ["finish","finishing","to finish","to finishing"], 2, "promise 接 to V"],
 ],
 c:[  // 克漏字、文意選填
   ["I dressed up ____ Ronald McDonald.", ["in","as","for","with"], 1, "dress up as 打扮成"],
 ]
}
```

每一題的格式是 `[題幹, [四個選項], 正解索引, 解析]`，**正解索引從 0 開始**（0=A、1=B、2=C、3=D）。
遊戲裡 🛋️ 沙發之類的家具各自綁定 `v`／`g`／`c` 其中一種題型，所以三種都放一些比較好；
某一種留空也不會壞，系統會自動改出別種題目。

## 要設定段考範圍

找到 `const PRESETS=[`，裡面已經先寫好了：

```js
const PRESETS=[
 {name:"課本四課混合",   ids:["B1L1","B1L2","B3L1","B3L2"]},
 {name:"高一第一次段考", ids:["B1L1","B1L2"]},
 {name:"高二第一次段考", ids:["B3L1","B3L2"]},
 {name:"學測衝刺（單字書）", ids:["GSAT"]},
 {name:"第二次段考範圍", ids:["B3L4","B3L5","B3L6"]}
];
```

規則是：**裡面列的課全部都存在時，那顆按鈕才會出現**在選擇畫面上。
所以段考範圍可以先寫好放著，等 `B3L2`、`B3L3` 的題庫加進 `UNITS` 之後，
「第一次段考範圍」就會自動冒出來，不用再改任何程式。

## 要改地圖或關卡

在 `const LEVELS=[` 裡，每一關有自己的 `map`（30×17 的字串陣列，`#` 是牆）、
`furn`（家具座標／圖示／題型）、`wp`（阿嬤巡邏點）、`items`（道具名稱）、
`days`（天數）、`gspeed`（阿嬤速度）。要加第三關就再加一個物件。
