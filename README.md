# Priscilla English｜恐怖阿嬤的英文逃脫

高中英文單字／文法／克漏字的 2D 逃脫遊戲。單一 `index.html`，沒有任何外部相依，手機／平板／電腦直接開就能玩。

**遊戲網址**：https://priscillalearn-ops.github.io/granny-escape-b3l1/

題目取自《GSAT 英文單字旗艦版：從字根邏輯到必背搭配詞》共 904 個單字。

`GSATPAST` 是 110～115 六年的學測英文考古題，三種題型是：詞彙題、綜合測驗、文意選填。

文意選填原本是 (A)～(J) 十選一，為配合遊戲格式改成「正解＋3 個同組誘答」的四選一。
篇章結構與閱讀測驗因為需要閱讀整篇文章，不適合這個遊戲的答題節奏，沒有收錄。

`TOEIC` 這一課的三種題型分別是：字義（中英互選）、同義字與商務情境用語、例句填空，
題目取自《多益單字》647 個商務單字與《多益購物場景》的商務／旅遊／人事／辦公室情境術語。

按「開始逃脫」後會先出現**選擇範圍**畫面，可以單選一課，也可以複選好幾課混著出題。

## 要新增一課的題目

編輯 `index.html`，找到最上面的 `const UNITS=[` ，在陣列裡再加一個物件：

```js
{
 id:"B3L2",                         // 代號，不能跟別課重複
 name:"B3 L2　課文標題",             // 選單上顯示的全名
 short:"B3 L2",                     // HUD 上顯示的短名
 src:{ v:"B3 L2 單字・片語",
       g:"B3 L2 文法：⋯⋯",
       c:"B3 L2 克漏字・文意選填" },  // 答題時顯示在題目上方的出處
 v:[  // 單字、片語
   ["「僱用」的英文是？", ["employ","deserve","adapt","collaborate"], 0, "employ (vt.) 僱用"],
 ],
 g:[  // 文法
   ["Kevin promised ____ the report.", ["finish","finishing","to finish","to finishing"], 2, "promise 接 to V"],
 ],
 c:[  // 克漏字、文意選填
   ["I dressed up ____ Ronald McDonald.", ["in","as","for","with"], 1, "dress up as 打扮成"],
 ]
}
```

每一題的格式是 `[題幹, [四個選項], 正解索引, 解析]`，**正解索引從 0 開始**（0=A、1=B、2=C、3=D）。
遊戲裡 🛋️ 沙發之類的家具各自綁定 `v`／`g`／`c` 其中一種題型，所以三種都放一些比較好；
某一種留空也不會壞，系統會自動改出別種題目。

## 要設定段考範圍

找到 `const PRESETS=[`，裡面已經先寫好了：

```js
const PRESETS=[
 {name:"課本四課混合",   ids:["B1L1","B1L2","B3L1","B3L2"]},
 {name:"高一第一次段考", ids:["B1L1","B1L2"]},
 {name:"高二第一次段考", ids:["B3L1","B3L2"]},
 {name:"學測衝刺（單字書）", ids:["GSAT"]},
 {name:"多益衝刺（商務職場）", ids:["TOEIC"]},
 {name:"第二次段考範圍", ids:["B3L4","B3L5","B3L6"]}
];
```

規則是：**裡面列的課全部都存在時，那顆按鈕才會出現**在選擇畫面上。
所以段考範圍可以先寫好放著，等 `B3L2`、`B3L3` 的題庫加進 `UNITS` 之後，
「第一次段考範圍」就會自動冒出來，不用再改任何程式。

## 要改地圖或關卡

在 `const LEVELS=[` 裡，每一關有自己的 `map`（30×17 的字串陣列，`#` 是牆）、
`furn`（家具座標／圖示／題型）、`wp`（阿嬤巡邏點）、`items`（道具名稱）、

## 班級排行榜（老師設定，約 5 分鐘）

學生破關或失敗後，成績會自動上傳到**你自己的 Google 試算表**，並在遊戲裡顯示全班排名。
沒設定的話這個功能完全不會出現，遊戲其他部分照常運作。

### 步驟

1. 開一個新的 Google 試算表（sheets.new），檔名隨意，例如「恐怖阿嬤成績」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上本專案的 **`leaderboard.gs`** 全部內容，存檔。
4. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 「執行身分」選 **我**
   - 「誰可以存取」選 **任何人**　←（很重要，學生沒有 Google 帳號也要能用）
   - 按「部署」，第一次會要你授權，一路允許
5. 複製它給你的**網頁應用程式網址**（長得像 `https://script.google.com/macros/s/AKfy.../exec`）。
6. 打開 `index.html`，找到最上面這一行，把網址貼進引號中間：
   ```js
   const BOARD_URL = "";
   ```
7. 存檔、`git push`，等 GitHub Pages 重建完就生效了。

> **驗證方法**：開無痕視窗貼上那串網址，看到 `{"ok":true,...}` 才算設定正確；
> 跳出 Google 登入畫面代表「誰可以存取」不是「任何人」。

> **改了程式碼要重新部署**：Apps Script 的網頁應用程式吃的是「版本」，
> 改完程式碼要走 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不會變。

### 學生怎麼用

- 第一次玩會在標題畫面看到「👤 還沒設定名字」，點一下輸入**名字（或座號）**和**班級**。
- 名字存在他自己的手機裡，下次不用再輸入。
- 破關或天數用完後，成績自動上傳，結束畫面會顯示「✅ 成績已上傳」。
- 標題畫面和結束畫面都有「🏆 班級排行榜」可以看排名，能用班級和題庫範圍篩選。

### 排名規則

破關的人排前面 → 答對題數多的前面 → 用的天數少的前面。**每人只顯示最好的一次成績**。

### 你會拿到什麼

試算表裡的 `scores` 工作表會累積每一筆紀錄：時間、名字、班級、題庫範圍、關卡、天數、答對、答錯、是否破關、難度。
可以直接排序、篩選、做成圖表，或當平時成績使用。

### 技術備註

- 上傳和讀取**都走 GET**。Apps Script 的 POST 在跨網域會被瀏覽器的 CORS 擋掉，這是 Google 的限制。
- Google 偶爾會回傳一個 HTML 錯誤頁而不是 JSON（資料其實已寫入），所以讀取會自動重試 3 次，
  上傳若拿到非 JSON 回應會改用「讀回排行榜確認」的方式判斷成功與否。
- **排行榜只在 GitHub Pages 網址上有效**。Artifact 版因為安全限制不能連外部服務，會顯示上傳失敗 —— 給學生的一律用 GitHub Pages 網址。

### 注意

- 學生輸入的名字**全班都看得到**，建議請他們用座號或暱稱。
- 這是「誰有網址誰就能寫入」的設計（因為學生不登入），理論上有人亂填也寫得進去。
  班級競賽用沒問題；如果要當正式成績，記得跟試算表裡的紀錄對一下。

## 更新網站

```bash
git add -A && git commit -m "更新題庫" && git push
```

GitHub Pages 會自動重建，**網址不變**，學生重新整理就是新版。
