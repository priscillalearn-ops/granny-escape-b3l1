# 恐怖阿嬤的英文逃脫 — B3 L1

龍騰高中英文 **B3 Lesson 1《The Day I Broke the Rules》**的 2D 英文逃脫遊戲。
單一 `index.html`，沒有任何外部相依，手機／平板／電腦都能直接玩。

**遊戲網址**：https://priscillalearn-ops.github.io/granny-escape-b3l1/

## 內容
- 題庫 206 題，全部取自該課講義
  - 單字・片語 65 題
  - 文法（不定詞 ＋ it 虛主詞／受詞）94 題
  - 克漏字・文意選填 47 題
- 兩關：第 1 關「阿嬤的家」、第 2 關「阿嬤的醫院」
- 虛擬搖桿操控、🤡 紅鼻子無敵道具（答對 5 題充能一次）、自動存檔、錯題複習

## 操作
| | 移動 | 互動 | 跑 | 無敵 |
|---|---|---|---|---|
| 電腦 | WASD／方向鍵 | E | Shift | Q |
| 手機 | 左半邊按住拖動 | 搜查鈕 | 搖桿推到底 | 無敵鈕 |

## 要改題庫
編輯 `index.html` 最上方的 `BANK` 物件，格式為 `[題幹, [四個選項], 正解索引, 解析]`。
地圖與家具在 `LEVELS` 陣列裡。
